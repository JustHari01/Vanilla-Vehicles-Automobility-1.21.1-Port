# Local port status

Target: Automobility (UNOFFICIAL), NeoForge 1.21.1. This repository is a separate working copy; the user's existing Automobility checkout and main game profile were not modified. No Modrinth or CurseForge upload has been made.

## Source assets and visual fidelity

`asset-fidelity.json` is regenerated by `tools/audit_asset_fidelity.py` against the supplied `.mcaddon`. All 218 runtime PNG textures are byte-for-byte identical to source. Bone, cube, and UV data is identical in all 8 vehicle models and 9 additional prop/NPC models. All 61 split animation frames match source pixels. The 99 WAV sounds have Java Ogg Vorbis conversions, so the audio files are lossy and not byte-identical. The two outer pack icons are not runtime assets and are excluded from the texture count.

This checks transferred source data, not visual parity between Bedrock and Java. Bedrock color-mask materials use approximate Java per-bone tinting. MER/PBR channels, emissive behavior, alpha compositing, and every animation controller are not reproduced exactly. The port currently uses vehicle wheel/propeller motion, fuel/status indicators, selected animation-sheet frames, and a subset of source mech, boat, balloon, and Prismer loops. Sticker rendering exists only on models with a sticker overlay. Client screenshots are saved under `neoforge/run-client/screenshots/`.

## Implementation

- Eight separate rideable vehicle entities with server-controlled movement, flight, balloon lift, submarine effects, seats, mob cargo, customization, storage, repairable Tesla helmet, projectiles, charge/boost, smoke, compressor, flags, wind vane, Mechanic trades, guide pages, and converted recipes.
- GeckoLib 4.9.3 is a required runtime dependency. The combined JAR contains Automobility and the Vanilla Vehicles port under the same `automobility` mod id; do not install it beside another Automobility JAR.
- Local test version is `0.5.0.h-vv1-localtest`. Original Blockworks assets remain attributed to Blockworks and are not assigned Automobility's MIT license; see `ASSET-RIGHTS.md`.

## Validation record

- Dedicated development server passed 6,000 ticks. All eight vehicles, riders, the original Automobility automobile, and a Mechanic survived. The measured mean server tick time was about 1.0 ms in this minimal flat-world test. Movement, flight, boost/cooldown, fuel, dye/sticker, seats, cargo, projectile, recipes, storage, and compressor checks passed.
- The same saved world passed a second-process reload: all 8 vehicle UUIDs, entity kinds, fuel values, dyes, stickers, and 3 stored diamonds per vehicle were restored. The QA harness detaches simulated riders after gameplay checks because its fake players have no playerdata; vanilla normally stores an occupied single-player vehicle through the player's saved root-vehicle data.
- A client run passed all 8 vehicle renders, actual keyboard-driven movement and fuel use, guide and plane guide page, vehicle storage, compressor inventory, and Mechanic trading screen. Screenshots include `vv-minecar.png`, `vv-logcar.png`, `vv-mobtruck.png`, `vv-plane.png`, `vv-hot_air_balloon.png`, `vv-steamboat.png`, `vv-prismer.png`, and `vv-mech.png`. The run emitted a shader sampler warning for `rendertype_entity_translucent_emissive`; it did not stop the run or prevent the tested models from rendering.
- A clean production JAR audit passed: 218 source PNGs identical, 8 vehicle definitions, 51 recipes, attribution included, and development QA classes absent. The packaged JAR booted in a separate production server directory with only that combined Automobility JAR plus GeckoLib 4.9.3. `summon bw_vv:minecar` and `summon bw_vv:mech` succeeded; the server saved and shut down cleanly. GeckoLib emitted its own missing-refmap warning; Automobility's two mixin configs no longer reference a refmap that this NeoForge-only build does not generate.

## Limits

This local test does not cover the user's full installed modpack, every in-game GUI path, or all Bedrock visual/material behavior. Use a copied instance and copied world. The local-test ZIP is not a public release and has not been uploaded.
