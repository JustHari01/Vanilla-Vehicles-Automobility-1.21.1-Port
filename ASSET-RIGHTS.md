# Asset attribution and scope

Automobility's original code is covered by its included MIT license.

Vanilla Vehicles 1.0.2 models, textures, sounds, names and original behaviour data
come from the user-supplied Blockworks addon. They remain Blockworks material;
the Automobility MIT license does not relicense these assets.

The port maintainer stated in this conversation on 2026-10-11 that the author
gave permission to port and publish the addon, including its assets. This file
records that user-provided statement; it is not an independent verification or
a new grant of permission to third parties. No separate permission document or
broader redistribution terms are included in this checkout.

The Java port is by JustHari01 with AI assistance. The local test artifact has
not been uploaded to Modrinth or CurseForge. Platform release metadata and the
remaining visual-parity work are still pending.
